# NEST Messages — Home Page

A ready-to-run **Vite + React + Tailwind** project.

## Quick start (Cursor/VS Code)

```bash
npm install
npm run dev
```

Then open the local URL printed in your terminal.

## Build for production

```bash
npm run build
npm run preview
```

## Notes
- Tailwind is already configured (see `tailwind.config.js` and `postcss.config.js`).
- Edit the content in `src/App.jsx` and styles in `src/styles.css`.
- No backend wired; the signup form is non-functional by default.
